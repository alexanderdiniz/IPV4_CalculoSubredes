📌 Arquitetura e Engenharia de Sub-redes IPv4

O Subnetting (Sub-roteamento) é o processo de divisão lógica de uma rede IP física em múltiplas redes menores. Esta prática maximiza a eficiência do roteamento, reduz domínios de broadcast, otimiza o desempenho dos comutadores (switches) e fortalece políticas de segurança por segmentação de firewall.

Total de Bits

Um endereço IPv4 é formado por 32 bits organizados em 4 octetos binários de 8 bits cada.

Network ID vs Host ID

A máscara especifica os bits de roteamento (Rede) e os bits para endereçamento local (Hosts).

Notação CIDR

O prefixo CIDR (ex: /24) define graficamente a quantidade contínua de bits `1` na máscara.

Antes do modelo CIDR (1993), a Internet utilizava arquitetura rígida baseada no primeiro octeto do IP. Compreender este modelo é fundamental para exames de certificação e análise histórica de roteamento.

🔒 Faixas Privadas (RFC 1918)

  • • Classe A: 10.0.0.0 até 10.255.255.255 (/8)
  • • Classe B: 172.16.0.0 até 172.31.255.255 (/12)
  • • Classe C: 192.168.0.0 até 192.168.255.255 (/16)

⚠️ Endereços Reservados Especiais

  • • 127.0.0.1 (127.0.0.0/8): Loopback de diagnóstico interno
  • • 0.0.0.0/0: Rota padrão / qualquer rede
  • • 255.255.255.255: Broadcast limitado na rede local

🧠 Fluxo Lógico e Método do "Número Mágico"

Este diagrama sintetiza os cálculos rápidos de cabeça através do Número Mágico ($2^{32-\text{prefixo}}$ ou $256 - \text{octeto crítico}$):

1. Bits de Host

Subtração dos bits CIDR do total de 32 bits IPv4.

8 bits (32 - 24)
2. Bitwise AND

Operação binária lógica entre IP e Máscara para extrair o ID da Rede.

192.168.1.50 AND 255.255.255.0
3. Número Mágico (Salto)

Tamanho do bloco calculado por 256 - octeto crítico.

256 IPs (256 total)
4. IPs Úteis

Desconto dos endereços de Rede e Broadcast (2^H - 2).

254 hosts (256 - 2)

📝 Metodologia de Cálculo em 6 Passos Systematicos

Passo 1: Sub-redes Necessárias

Calcule $2^n \ge \text{sub-redes}$, onde $n$ é a quantidade de bits emprestados de host.

Passo 2: Dimensionar Hosts

Confirme se $2^h - 2 \ge \text{hosts}$, sendo $h$ os bits de host restantes.

Passo 3: Nova Máscara CIDR

Soma-se o prefixo original + $n$ bits emprestados (ex: $/24 + 3 = /27$).

Passo 4: Octeto Crítico e Salto

Identifique o octeto alterado. Salto = $256 - \text{octeto}$ ou $2^{32-\text{prefixo}}$.

Passo 5: Sequenciamento de Blocos

Crie os IDs de rede somando o salto consecutivamente ($0, \text{salto}, 2\times\text{salto}, \dots$).

Passo 6: Broadcast e Intervalos

Broadcast é $(\text{Próxima Rede} - 1)$. Os IPs utilizáveis ficam no intervalo central.

💻 Operação Bitwise AND no Hardware

Os roteadores não realizam cálculos em base decimal. Para determinar se um pacote deve ser encaminhado localmente ou para um Gateway, a interface de rede executa uma porta lógica AND bit por bit entre o IP de destino e a máscara.

Bit IP: 1 AND Bit Máscara: 1 = 1
Bit IP: 1 AND Bit Máscara: 0 = 0
Bit IP: 0 AND Bit Máscara: 1 = 0

📜 Do Classful (A, B, C) ao CIDR

Em 1993, a IETF introduziu o CIDR (Classless Inter-Domain Routing - RFC 1519). O CIDR eliminou a rigidez de classes, permitiu agregação de rotas (Supernetting) na tabela de roteamento global do BGP e introduziu o conceito de VLSM.

✍️ Exercícios Práticos Resolvidos (Baseados no PDF)

Exercício 1: Identificação de Classe

Identifique a classe e a máscara padrão do endereço 190.10.5.7.

Ver Gabarito Comentado
O 1º octeto (190) está no intervalo 128-191. Portanto, trata-se de um endereço da Classe B com máscara padrão /16 (255.255.0.0).
Exercício 2: Conversão de Prefixo

Converta o prefixo /28 em máscara decimal e determine a quantidade de hosts úteis.

Ver Gabarito Comentado
Máscara Decimal: 255.255.255.240.
Bits de Host: 32 - 28 = 4 bits.
Hosts Úteis: 2^4 - 2 = 16 - 2 = 14 hosts úteis.
Exercício 3: Subnetting /24 para 4 Sub-redes

Divida o bloco 192.168.50.0/24 em 4 sub-redes e liste as faixas.

Ver Gabarito Comentado
Para 4 sub-redes: 2^n = 4 => n = 2 bits emprestados => Novo Prefixo: /26.
Salto = 256 - 192 = 64.
• Sub-rede 1: 192.168.50.0/26 (Útil: .1 até .62, Broadcast: .63)
• Sub-rede 2: 192.168.50.64/26 (Útil: .65 até .126, Broadcast: .127)
• Sub-rede 3: 192.168.50.128/26 (Útil: .129 até .190, Broadcast: .191)
• Sub-rede 4: 192.168.50.192/26 (Útil: .193 até .254, Broadcast: .255)
Exercício 4: Identificar Rede em Octeto Intermediário

Qual é a rede a que pertence o IP 172.16.45.200/20?

Ver Gabarito Comentado
Máscara /20 = 255.255.240.0. Octeto Crítico: 3º (240).
Salto = 256 - 240 = 16 no 3º octeto (0, 16, 32, 48...).
O valor 45 do IP está entre 32 e 47.
Logo, o Endereço de Rede é: 172.16.32.0.
Exercício 5: Dimensionamento por Necessidade

Qual o menor prefixo para acomodar 300 hosts em uma mesma sub-rede?

Ver Gabarito Comentado
Fórmula: 2^h - 2 >= 300 => 2^h >= 302.
Para h = 8 => 256 IPs (insuficiente).
Para h = 9 => 512 IPs (510 úteis).
Prefixo = 32 - 9 = /23 (Máscara 255.255.254.0).
